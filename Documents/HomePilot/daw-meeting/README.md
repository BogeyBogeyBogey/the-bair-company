## Kernpositie

FacadePilot is geen leadgenerator. Het is property intelligence + partner activation + learning database voor producenten die via een verwerkersnetwerk verkopen.

Voor DAW betekent dat: niet "adressen kopen", maar zien waar Capatect/gevelisolatiekansen zitten, welke partner welke kansen krijgt, wat elke campagnegolf leert, en hoe dat terugvloeit naar regio-, partner- en productbeslissingen.

# HomePilot Pilots

This folder is reserved for product modules that run on top of HomePilot Core.

Planned modules:

- `facadepilot`: facade renovation opportunities.
- `windowpilot`: window and glazing replacement opportunities.
- `roofpilot`: roof renovation, insulation, and solar-adjacent opportunities.
- `gardenpilot`: garden redesign and outdoor living opportunities.
- `poolpilot`: pool feasibility and premium garden opportunities.
- `porchpilot`: entrance, porch, and front-of-house opportunities.
- `drivewaypilot`: driveway, paving, drainage, and EV-ready opportunities.

The existing FacadePilot code currently lives at `../../FacadePilot`. Do not move
it mechanically until the imports, generated output folders, dashboard start
scripts, and deployment paths are updated in one controlled migration.

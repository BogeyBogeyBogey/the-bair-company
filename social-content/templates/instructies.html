Hoe gebruik je de templates?

Elke template is een HTML-bestand dat je opent in een teksteditor, de tekst aanpast, en vervolgens opent in je browser om een screenshot te maken. Geen Photoshop, geen Canva, geen design-kennis nodig.

← Terug naar alle templates
STAP 01
Open het template-bestand
Kies een template uit het overzicht en klik met de rechtermuisknop op het HTML-bestand. Kies "Open met" en selecteer een teksteditor. Op Mac werkt TextEdit (zet in "platte tekst"-modus) of het gratis Visual Studio Code. Op Windows werkt Kladblok of Notepad++.
TIP
Gebruik NIET Word of Google Docs — die voegen opmaak toe die het bestand breekt.
STAP 02
Pas de tekst aan bovenaan het bestand
Bovenaan elk bestand staat een blok met const CONTENT = { ... }. Dit is het enige deel dat je aanpast. Verander de tekst tussen de aanhalingstekens. 
// ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
// ✏️ WIJZIG HIER JE CONTENT:
// ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
const CONTENT = {
  headline: "Jouw nieuwe tekst hier",
  body: "En hier je beschrijving.",
};
BELANGRIJK
Verander ALLEEN de tekst tussen de aanhalingstekens " ". Raak de rest van de code niet aan.
STAP 03
Afbeeldingen toevoegen (optioneel)
Sommige templates hebben een veld voor een screenshot of afbeelding. Zet je afbeelding in dezelfde map als de templates (of in een submap) en vul het pad in. 
const CONTENT = {
  heading: "Nieuw project live",
  screenshot: "screenshots/mijn-project.jpg",
};
TIP
Gebruik bij voorkeur afbeeldingen in liggende verhouding (16:9) voor LinkedIn-templates en staande verhouding (4:5 of 9:16) voor carousel en story.
STAP 04
Open in je browser
Sla het bestand op en dubbelklik erop (of sleep het naar Chrome/Safari/Firefox). Je ziet nu je aangepaste post op exact het juiste formaat.
STAP 05
Maak een screenshot
Gebruik de ingebouwde screenshot-tool van je browser om het canvas op te slaan als PNG. 
// Chrome:
Rechtermuisknop op de afbeelding → "Inspecteren"
In DevTools: Rechtermuisknop op het <div class="canvas"> element
→ "Capture node screenshot"

// Of de makkelijke manier:
macOS: Cmd + Shift + 4 → selecteer het canvas
Windows: Win + Shift + S → selecteer het canvas
PRO TIP
De "Capture node screenshot" methode in Chrome DevTools geeft je automatisch het exacte pixelformaat (bv. 1080×1350 voor carousel). Dat is altijd de beste methode.
STAP 06
Posten!
Upload de screenshot naar Instagram, LinkedIn of je Stories. Voor carousels maak je meerdere slides door steeds een ander template-bestand aan te passen.

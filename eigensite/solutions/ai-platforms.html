Three things: performant, well-structured code that integrations can hook into; clean data and event tracking; and an architecture where AI features (chat, personalisation, automation) are add-ons — not rebuilds.

Yes — it's included in how we work. Identity, copy in multiple languages, photography direction and motion come from the same team that writes the code. One vision, one result.
